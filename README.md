# Tizandish Image Studio — v2.8.1.1

ویرایشگر و مبدل تصویر فارسی و واکنش‌گرا؛ پردازش محلی در مرورگر.

## امکانات نسخه 2.8.1.1
- ورود تصویر با انتخاب فایل، Drag & Drop و Clipboard
- رمزگشایی بومی JPEG/JPG، PNG، WebP، GIF، BMP، SVG و AVIF (بسته به مرورگر)
- تشخیص امضای باینری فایل (Magic Bytes) برای PNG، JPEG، GIF، BMP، TIFF، WebP، AVIF، HEIC و SVG؛ تشخیص تا حد زیادی مستقل از MIME و پسوند است
- تشخیص فرمت از امضای باینری فایل (Magic Bytes)، حتی اگر MIME یا پسوند فایل اشتباه/ناقص باشد؛ پسوند و ساختار با هم اعتبارسنجی می‌شوند
- پشتیبانی HEIC/HEIF با مبدل جدید heic-to 1.6.7 در صورت نبود رمزگشایی بومی
- خواندن TIFF با UTIF.js و Pako برای فشرده‌سازی Deflate/Inflate؛ بررسی IFDهای موجود، انتخاب بزرگ‌ترین تصویر قابل‌خواندن و اصلاح جهت EXIF/TIFF
- دوربین زنده با انتخاب دوربین جلو/عقب، تشخیص خطای مجوز، جلوگیری از تلاش مجدد بی‌مورد و توقف جریان هنگام بستن/تعویض
- روش جایگزین دوربین گوشی با انتخابگر بومی دستگاه
- تبدیل مستقل عکس اصلی به PNG/JPEG/WebP/AVIF بدون حذف پس‌زمینه
- خروجی با تشخیص MIME واقعی؛ پسوند فایل با نوع واقعی خروجی هماهنگ می‌شود و در صورت عدم ساخت خروجی فرمت انتخابی، تبدیل‌گر مستقل به PNG برمی‌گردد و در صورت رد encoder مرورگر، تبدیل مستقل به PNG جایگزین می‌شود
- تغییر اندازه با حفظ نسبت، محدودسازی تصاویر بسیار بزرگ برای کاهش مصرف حافظه
- ابزارهای برش، دوربری، پرسپکتیو، چرخش، ذره‌بین و قلم جادویی

## نکات سازگاری و محدودیت‌ها
- رمزگشایی JPEG/PNG/WebP/GIF/BMP/SVG/AVIF به موتور مرورگر وابسته است؛ فرمت‌های متحرک مانند GIF در خروجی به یک تصویر ثابت تبدیل می‌شوند.
- HEIC/HEIF و TIFF ممکن است در اولین استفاده ممکن است نیازمند دریافت کتابخانه از CDN و اتصال اینترنت باشند. TIFFهای Deflate نیز به Pako نیاز دارند که هنگام بازکردن TIFF بارگیری می‌شود.
- دوربین زنده تنها در HTTPS یا localhost و پس از اجازهٔ صریح کاربر در دسترس است؛ انتخابگر دوربین گوشی جایگزین است.
- فایل‌های RAW مانند CR2/CR3/NEF/ARW/DNG به‌طور کامل توسعه داده نمی‌شوند؛ بهتر است پیش‌نمایش JPEG یا TIFF صادرشده از دوربین استفاده شود.
- برای پایداری موبایل، تصاویر بزرگ به حداکثر ۲۴ مگاپیکسل/حداکثر ضلع ۱۲۰۰۰ پیکسل کاهش داده می‌شوند. سقف ورودی ۱۲۰ مگابایت است.
- خروجی JPEG برای نواحی شفاف پس‌زمینهٔ سفید می‌گذارد؛ PNG/WebP/AVIF در تبدیل عکس اصلی شفافیت را حفظ می‌کنند.
- Canvas ممکن است فراداده‌هایی مانند EXIF/GPS و بعضی پروفایل‌های رنگ را حذف کند.

## انتشار
مخزن `arashrajabifar1-tech/tizandish-image-studio` را در Vercel Import کنید. Framework Preset را روی Other بگذارید و Build Command و Output Directory را خالی نگه دارید. پس از اتصال Git، push روی `main` انتشار خودکار را فعال می‌کند.

## آزمون
نشانی صفحه را با `?selftest=1` باز کنید. آزمون داخلی یک تصویر نمونهٔ مصنوعی می‌سازد، خروجی‌های در دسترس PNG/WebP/JPEG/AVIF را رمزگذاری و دوباره می‌خواند، و یک TIFF RGB کوچک واقعی را از بایت‌های ساخته‌شده تست می‌کند؛ تشخیص امضای PNG/JPEG و تطبیق MIME نیز آزمایش می‌شود. پشتیبانی سخت‌افزار دوربین و فایل HEIC واقعی همچنان باید با دستگاه و نمونهٔ واقعی بررسی شود.
