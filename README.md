# Tizandish Image Studio — v2.5

ویرایشگر تصویر فارسی و واکنش‌گرا؛ اجرای مستقیم در مرورگر و بدون نیاز به نصب برنامه.

## دریافت و اجرا
- فایل تکی: [index.html](./index.html)
- برای دانلود کل پروژه: در GitHub روی **Code → Download ZIP** بزنید.
- پس از دریافت ZIP، آن را استخراج کنید و فایل `index.html` را در مرورگر باز کنید.

## امکانات نسخه 2.5
- ابزار برش آزاد با مسیر چندنقطه‌ای
- برش بیضی و دایره
- ذره‌بین دایره‌ای برای انتخاب دقیق‌تر
- حفظ ابزار پرسپکتیو چهارگوشه‌ای
- قلم جادویی با انتخاب ناحیه بر اساس رنگ، تنظیم اندازه و حساسیت، Undo و پاک‌سازی موضعی
- پردازش تصویر در مرورگر

## نکته درباره قلم جادویی
موتور پاک‌سازی از OpenCV.js استفاده می‌کند و در اولین اجرای پاک‌سازی، کتابخانه از اینترنت بارگیری می‌شود. بنابراین برای این قابلیت اتصال اینترنت لازم است. انتخاب هوشمند در این نسخه مبتنی بر رنگ و پیوستگی پیکسل‌هاست و هنوز تشخیص معنایی کامل متن/اشیاء یا OCR نیست.

## انتشار در Vercel
این پروژه یک صفحه استاتیک است:
1. در Vercel گزینه **Add New → Project** را انتخاب کنید.
2. مخزن `arashrajabifar1-tech/tizandish-image-studio` را Import کنید.
3. Framework Preset را روی **Other** قرار دهید.
4. Build Command و Output Directory را خالی بگذارید.
5. Deploy را بزنید.

اگر مخزن در فهرست نبود، GitHub را در Vercel متصل کنید و دسترسی همین مخزن را به GitHub App بدهید.

## وضعیت
منبع نسخه 2.5 در شاخه `main` قرار دارد. آزمون‌های ساختاری و توابع هندسی/انتخاب ناحیه بررسی شده‌اند؛ آزمون نهایی تعامل لمسی و Inpainting در مرورگر واقعی هنوز باید انجام شود.
