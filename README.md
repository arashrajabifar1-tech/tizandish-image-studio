## سازگاری و محدودیت‌ها
- پشتیبانی فرمت‌های ورودی به موتور مرورگر وابسته است؛ GIF متحرک در این ویرایشگر به تصویر ثابت/فریم قابل‌نمایش تبدیل می‌شود.
- HEIC/HEIF و TIFF ممکن است در اولین استفاده به دریافت کتابخانه از CDN نیاز داشته باشند. TIFFهای Deflate نیز Pako را به‌صورت موردی بارگیری می‌کنند.
- دوربین زنده فقط در HTTPS یا localhost و پس از اجازهٔ کاربر کار می‌کند؛ در غیر این صورت می‌توان از انتخابگر دوربین گوشی استفاده کرد.
- فایل‌های RAW مانند CR2/CR3/NEF/ARW/DNG در این نسخه به‌طور کامل تبدیل نمی‌شوند؛ پیش‌نمایش JPEG یا TIFF صادرشده از دوربین را انتخاب کنید.
- برای پایداری موبایل، عکس‌های بیش از ۲۴ مگاپیکسل یا ضلع ۱۲۰۰۰ پیکسل کوچک می‌شوند. سقف حجم ورودی ۱۲۰ مگابایت است.
- خروجی JPEG نواحی شفاف را سفید می‌کند؛ PNG/WebP/AVIF در تبدیل مستقل می‌توانند شفافیت منبع را حفظ کنند.
- Canvas ممکن است بخشی از فراداده‌ها مانند EXIF/GPS و بعضی پروفایل‌های رنگ را حذف کند.

## آزمون داخلی
نشانی صفحه را با `?selftest=1` باز کنید. آزمون داخلی خروجی‌های PNG/JPEG/WebP/AVIF را در مرورگرِ پشتیبان رمزگذاری و دوباره می‌خواند، امضای PNG/JPEG و برند سازگار AVIF را بررسی می‌کند، اصلاح جهت EXIF را می‌آزماید و یک TIFF RGB کوچک ساخته‌شده از بایت‌ها را می‌خواند. آزمون نهایی دوربین فیزیکی و فایل HEIC واقعی باید روی دستگاه واقعی نیز انجام شود.

## آزمون خودکار مرورگر
در محیطی با Node.js و Python:

## نسخهٔ 3.4.0 — شاخهٔ آزمایشی

- شکست موتور AI دیگر به‌صورت خودکار با پردازش کلاسیک پنهان نمی‌شود؛ وضعیت خطا صریح است و کاربر باید آگاهانه حالت کلاسیک را انتخاب کند.
- API تغییر زاویه از مسیر امن هم‌مبدأ `/api/viewpoint` عبور می‌کند؛ کلید ارائه‌دهنده در مرورگر قرار نمی‌گیرد.
- درگاه API از Pollinations Image Edits استفاده می‌کند و مدل از طریق متغیر محرمانه `POLLINATIONS_IMAGE_MODEL` انتخاب می‌شود.
- پاسخ استاندارد JSON Pollinations شامل `data[0].b64_json` و پاسخ باینری هر دو پشتیبانی می‌شوند؛ `response_format=b64_json` صریح ارسال می‌شود.
- اعتبارسنجی نوع و امضای تصویر، اندازه، طول prompt، مبدأ درخواست و timeout اضافه شده است. محدودکنندهٔ ۵ درخواست در دقیقه به‌صورت best-effort در هر نمونهٔ Function اضافه شده؛ برای محدودیت سراسری، Firewall/Rate Limit در Vercel یا یک KV مشترک لازم است.
- تست واحد API، بررسی syntax اسکریپت‌های HTML و آزمون مرورگر موبایل برای ورود تصویر، پردازش کلاسیک، مقایسهٔ قبل/بعد و helper برش اضافه شده‌اند.

### راه‌اندازی API تغییر زاویه در Vercel

در Project Settings → Environment Variables این مقادیر را فقط برای محیط Preview تنظیم کنید:
- `POLLINATIONS_API_KEY`: کلید محرمانهٔ Pollinations
- `POLLINATIONS_IMAGE_MODEL`: شناسهٔ دقیق مدل Image Edits که در حساب ارائه‌دهنده پشتیبانی و فعال است
- `VIEWPOINT_ALLOWED_ORIGINS`: اختیاری؛ مبدأهای اضافی مجاز، جداشده با کاما

کلید را هرگز در HTML، GitHub یا چت قرار ندهید. پس از تنظیم متغیرها، یک Preview deployment جدید بسازید.

**هزینه:** گزینهٔ «free» به معنی رایگانِ نامحدود نیست. Pollinations ممکن است برای استفاده به کلید و اعتبار حساب نیاز داشته باشد؛ قیمت و دسترسی مدل را پیش از استفاده بررسی کنید. در این شاخه هیچ کلید یا اعتبار پولی مصرف نشده است.
