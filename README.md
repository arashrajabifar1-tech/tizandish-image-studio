# Tizandish Image Studio — v2.6

ویرایشگر تصویر فارسی و واکنش‌گرا؛ اجرای مستقیم در مرورگر و بدون نیاز به نصب.

## دریافت و اجرا
- فایل برنامه: [index.html](./index.html)
- برای دانلود کل پروژه در GitHub از **Code → Download ZIP** استفاده کنید.
- ZIP را استخراج کنید و فایل `index.html` را در مرورگر باز کنید.

## امکانات نسخه 2.6
- ورود تصویر از فایل، کشیدن و رهاکردن (Drag & Drop) و Clipboard
- پشتیبانی از JPG/JPEG، PNG، WebP، GIF، BMP، SVG و AVIF با رمزگشایی بومی مرورگر
- تلاش برای بازکردن HEIC/HEIF با رمزگشایی بومی؛ در صورت نیاز تبدیل به PNG با heic2any
- خواندن TIFF با UTIF.js و تبدیل به تصویر قابل ویرایش
- دوربین زنده با انتخاب دوربین جلو/عقب، ثبت عکس با رزولوشن دوربین و توقف امن Stream
- گزینه جایگزین انتخاب عکس با دوربین گوشی در مرورگرهایی که getUserMedia ندارند
- چرخش ۹۰ درجه، برش آزاد، دوربری چندنقطه‌ای، برش بیضی و پرسپکتیو
- قلم جادویی با انتخاب رنگ‌محور و پاک‌سازی موضعی
- خروجی PNG، JPEG، WebP و AVIF در مرورگرهای سازگار
- بررسی MIME واقعی خروجی و اصلاح خودکار پسوند در صورت fallback مرورگر
- محدودیت ۱۲۰ مگابایت برای فایل ورودی و ۶۰ مگاپیکسل برای تصویر/خروجی برای کاهش خطر اتمام حافظه

## نکات سازگاری
- دوربین زنده به HTTPS (یا localhost)، پشتیبانی مرورگر و اجازه کاربر نیاز دارد. فایل دوربین گوشی به‌عنوان راه جایگزین وجود دارد.
- HEIC/HEIF و TIFF ممکن است برای تبدیل اولیه نیازمند دانلود کتابخانه از CDN و اتصال اینترنت باشند.
- پشتیبانی AVIF در خروجی وابسته به مرورگر است؛ نوع واقعی Blob بررسی می‌شود و پسوند نام فایل با نوع واقعی تطبیق می‌یابد.
- فایل‌های RAW دوربین (مانند CR2، NEF، ARW و DNG) در این نسخه به‌صورت کامل پردازش نمی‌شوند. در صورت امکان، JPEG یا TIFF خروجی دوربین را وارد کنید.
- فایل‌های بسیار بزرگ‌تر از محدودیت برنامه با پیام روشن رد می‌شوند تا حافظه گوشی یا مرورگر دچار فشار شدید نشود.
- خروجی JPEG پس‌زمینه سفید دارد؛ PNG/WebP/AVIF نیز مطابق طراحی فعلی ابزار، خروجی سفیدشده می‌سازند.

## انتشار در Vercel
این پروژه یک صفحه استاتیک است:
1. در Vercel گزینه **Add New → Project** را انتخاب کنید.
2. مخزن `arashrajabifar1-tech/tizandish-image-studio` را Import کنید.
3. Framework Preset را روی **Other** قرار دهید.
4. Build Command و Output Directory را خالی بگذارید.
5. Deploy را بزنید.

بعد از اتصال Git، تغییرات شاخه `main` به‌طور خودکار Deploy می‌شوند. اگر مخزن در فهرست نبود، GitHub را در Vercel متصل و دسترسی همین مخزن را فعال کنید.

## آزمون
با افزودن `?selftest=1` به آدرس صفحه، آزمون‌های داخلی نمایش داده می‌شوند. این آزمون‌ها ساخت و بازخوانی PNG/JPEG/WebP/AVIF را با یک تصویر نمونهٔ تولیدشده در مرورگر آزمایش می‌کنند. آزمون دوربین واقعی، مجوز سخت‌افزار و HEIC/TIFF باید روی دستگاه/مرورگری که آن فرمت‌ها را دارد هم انجام شود.
